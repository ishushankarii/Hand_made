HANDMADE ONLINE MARKETPLACE – PROBLEM STATEMENT

1. Title

Handmade Online Marketplace

2. Domain

E-Commerce / Online Shopping

3. Who is the user?

1. Customer – Can register, login, browse handmade products, add products to cart, place orders, and view order status.
2. Seller – Can add, update, and manage handmade products and view customer orders.
3. Admin – Can manage users, sellers, products, and orders.

4. What problem are we solving?

Many small handmade product sellers depend on social media or local shops to sell their products. Customers may find it difficult to discover different handmade products in one place and place orders easily. Sellers also need a simple platform to display their products and manage orders. The Handmade Online Marketplace provides a single online platform where customers can discover and purchase handmade products conveniently.

5. Proposed Solution

The application will provide the following features:

- User registration and login
- Customer and seller role management
- Browse handmade products
- Product categories
- Search and filter products
- View product details
- Add products to cart
- Place orders
- View order history and order status
- Sellers can add, edit, and delete their products
- Sellers can view and manage orders
- Admin can manage users, sellers, products, and orders

6. Core Entities / Database Tables

The main database tables are:

1. User
2. Seller
3. Product
4. Category
5. Cart
6. Order
7. OrderItem
8. Payment

7. User Roles & Permissions

Customer

- Register and login
- Browse products
- Search and filter products
- Add products to cart
- Place orders
- View order history

Seller

- Login
- Add products
- Update products
- Delete products
- View customer orders
- Update order status

Admin

- Manage customers and sellers
- Manage products and categories
- View and manage orders
- Monitor the overall application

8. Success Criteria

- A new user should be able to register and login successfully.
- A customer should be able to find a handmade product using search or categories.
- A customer should be able to add a product to the cart and place an order easily.
- A seller should be able to add and manage products.
- Admin should be able to manage users, products, and orders.
- The application should provide a simple and user-friendly shopping experience.

9. Out of Scope

The following features will not be included in the initial version:

- Real-time delivery tracking
- International shipping management
- Advanced recommendation system
- AI-based product recommendations
- Multiple payment gateway integrations
- Live chat between customers and sellers
- Mobile application
- Advanced analytics and reporting

10. Chosen Track

Java – Spring Boot

Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Java Spring Boot
- Database: MySQL
- IDE: Visual Studio Code
- Version Control: Git and GitHub
